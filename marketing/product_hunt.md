# Product Hunt Launch

**Tagline:**
Explain any topic — from kid-simple to genuinely deep. Free, instant, no signup.

**Description:**
Type anything. Get it explained across 5 levels — Level 1 is written for a curious 10-year-old, Level 5 assumes you want real depth.

That's the core. But there's a lot more:

**Learn:**
→ 5-level explanations on any topic, 40+ languages
→ Guided Paths for structured learning journeys
→ Flashcards, Notes, Library
→ Math tutor with interactive problems
→ Compare any two concepts side-by-side

**Play:**
→ Quiz Battle — two topics go head-to-head
→ Speed Run — race to Level 5
→ Spot Errors — find deliberate mistakes in explanations
→ Debate Mode — structured both-sides argument
→ Blackjack — bet your earned XP

**Progress:**
→ XP + streak system with daily login rewards
→ Solar System visualization of everything you've learned
→ Leaderboard and global rankings
→ XP Shop — spend earned XP on perks, themes, and permanent upgrades
→ Learning DNA fingerprint

**Social:**
→ Friends, Study Rooms, public profiles

100% free. No ads. No paywalls. Works without an account.

**Topics I've personally tested it on:** Why do cats purr / The 2008 financial crisis / How CRISPR works / The Trolley Problem / Quantum entanglement / Why music gives you chills

**Maker comment:**
I built this because I kept Googling things and getting either Wikipedia (too dense) or kids' sites (too shallow). The 5-level structure solves that — you pick your depth. I added the gamification because I wanted a daily reason to come back, and it worked better than I expected. Happy to answer anything.
